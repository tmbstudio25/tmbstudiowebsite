Content Manager

Edit TMB Studio's images, video, and text. Changes preview instantly in this browser — download and commit content.json to publish them for everyone.

How publishing works. This site has no server, so edits made here live only in this browser until you publish them.
  1. Edit fields below — each change auto-saves as a local preview.
  2. Use the preview links to open the live pages in a new tab and check how it looks.
  3. When you're happy, click Download content.json and replace the content.json file in your website's repository with it, then commit & push.
  4. If you uploaded new images/video as files (rather than pasting a path), also add those files to your repo's assets folder — see the hint under each upload.
